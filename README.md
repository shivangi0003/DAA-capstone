A Python project for courier parcel selection and delivery route
optimization using DAA algorithms.
Features
- Parcel data handling with CSV files
- Merge Sort for priority-based sorting
- 0/1 Knapsack for parcel selection
- Dijkstra's algorithm for shortest paths
- Nearest-Neighbor TSP for delivery routing
- Performance benchmarking with Matplotlib
Tech Stack
Python 3.14, VS Code, CSV, Matplotlib
Run the Project
python test_phase1.py
python test_phase2.py
python test_phase3.py
python test_phase4.py
Install Matplotlib if needed:
python -m pip install matplotlib
